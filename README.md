# Codepedia Dark Theme

A dark theme for Visual Studio Code, designed to be comfortable during long coding sessions.

| Specification | Details |
| --- | --- |
| Theme name | `codepdia` |
| Type | Dark (`vs-dark`) |
| Version | `2.3.0` |
| Font | Monaspace |
| Icon theme | Chalice Icon Theme |
